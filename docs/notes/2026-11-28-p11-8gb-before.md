# P-11: an 8 GB card before any change, Series X mode

What `main` uses on an 8 GB laptop card, measured before any work on P-11, so the change that
keeps the game inside the card's budget has a figure to beat. Nothing here quotes game data.

**Machine:** NVIDIA GeForce RTX 5060 Laptop GPU 8 GB (Windows budget for the game about
7,030 to 7,070 MB), driver 32.0.16.1714; Intel Core i7-13620H; 16 GB RAM; Windows 11 Pro build
26300.

**Build and run:** `main` at `36aa56b`, `cargo build --profile diag -p leonida --features diagnostics`,
`scripts\measure-run.ps1 -Console series-x`, profile `base` (its eight speed switches on), the
title rendering at 2560x1440. The scene is the opening, frames counted from 170 to 330 s after
launch. Memory was sampled every 5 s from the Windows `GPU Process Memory` counters and the
process's private bytes and working set, and read from the layer's once-a-second memory line.

| | Run 1 (first run of the build) | Run 2 |
|---|---|---|
| fps | 3.6 | 4.4 |
| Median frame | 272 ms | 226 ms |
| Card time / preparing / copying back | 48 / 139 / 61 ms | 59 / 115 / 58 ms |
| Card memory in use (second half median, peak) | 6,579 MB, 6,708 MB | 6,758 MB, 6,799 MB |
| Shared PC memory in use (second half median, peak) | 5,605 MB, 5,987 MB | 5,756 MB, 6,077 MB |
| Private bytes (peak) | 20,802 MB | 20,911 MB |
| Working set (peak) | 9,533 MB | 9,869 MB |
| Passes that made no texture copy for lack of room | 923 | 1,594 |
| Crash or device loss | none | none |

Run 2 is the figure to compare with: run 1 was the first run of a new build.

- The card stays a few hundred MB under its budget while about 5.7 GB more sits in shared PC
  memory, which the card reads over the bus. Render targets take about 2.7 GB of the card and
  copies of title-filled textures about 2 GB.
- Passes that find no room read an empty texture, which shows as black areas.
- Private bytes above the 16 GB of RAM mean Windows pages part of the game to disk.
- Series S mode is broken on `main`, so it has no figure here.
